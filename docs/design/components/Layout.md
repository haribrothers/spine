# Layout

**Package:** `@spine/ui` · **Platform:** Web · **Source:** `packages/ui/src/components/layout.tsx` · **Doc page:** none yet

Spacing-scale keys mapped to literal, fully-static Tailwind class names — not built via template-string interpolation (`` `p-${n}` ``), since Tailwind's content scanner can only pick up class names it can see as literal text, not ones assembled at runtime.

## Import

```tsx
import { Box, Flex, Grid, Container, Section } from "@spine/ui";
```
