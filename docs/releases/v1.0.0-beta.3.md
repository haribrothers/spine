The third beta of Spine 1.0. It runs on Apple Silicon Macs and ARM servers too, and it's the first one you can download without a GitHub account.

## Installing and upgrading

- **Intel, AMD and ARM:** the images are built for amd64 and arm64. Earlier betas were amd64 only, so on an ARM machine they stopped with "no matching manifest for linux/arm64".
- **No GitHub account needed:** the repository, the releases and the images are public. A server no longer needs a GitHub token or `docker login`.
- **Download only what you need:** install.sh, backup.sh, restore.sh, upgrade.sh, docker-compose.yml, Caddyfile and env.example. The README has a `curl` command that fetches them.
- **On your own computer:** `./install.sh --app-url http://localhost` runs Spine on plain HTTP for trying it out. The field app needs a real domain with HTTPS.
- **From beta.2:** `./upgrade.sh --version 1.0.0-beta.3`. It backs up first.

## New since beta.2

- **Demo data:** load a demo business to explore, then delete it and keep your real data. Or start a new install with it (`SEED_DEMO=true`).
- **Update notice:** Owners see "Spine <version> is available" when a new release is out.
- **On a phone's browser:** the web app works on a phone, and wide tables stay usable on small screens.
- **Accessibility:** every screen passed an accessibility audit, and Spine respects reduced-motion settings.
- **Error pages:** a missing page and an unexpected error each show a page that says what to do next.
- **Job photos:** delete a photo added by mistake, on the web or the phone. Photos open full screen on the phone.
- **GSTR-1:** releasing retention no longer shows as a supply of its own.
- **Security:** a CSV export can't carry a spreadsheet formula. The pre-1.0 security review is signed off.
- **Help:** the user guide and self-hosting guide are at spine.h4loom.com/docs, and in the app behind the **?** button.

The full list is in [CHANGELOG.md](https://github.com/haribrothers/spine/blob/main/CHANGELOG.md).
