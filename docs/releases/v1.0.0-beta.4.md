The fourth beta of Spine 1.0. Spine now opens on one port at any address, so you can reach it by `localhost` on its own machine and by its IP from every other device. HTTPS starts when you give it a domain.

## Before you upgrade

- **Your address stays as it was.** `./upgrade.sh --version 1.0.0-beta.4` keeps the port your install already used (80 for `http://localhost`). An `https://` install keeps its domain's certificate on ports 80 and 443. It backs up first, as always.
- **To use the new port and open Spine from other devices:** after the upgrade, set `SPINE_PORT=7746` in `.env`, put that port in `APP_URL` and `API_URL` (for example `http://192.168.1.20:7746` and `http://192.168.1.20:7746/api`), then run `docker compose --profile minimal up -d`.
- **On Coolify:** paste this release's `docker-compose.coolify.yml` over the old one, then redeploy. Your data and generated secrets stay.

## Installing

- **One port, any address:** a new install opens at `http://localhost:7746` on its machine and `http://<its IP>:7746` from other devices, over plain HTTP. Sign-in works at each of them. `./install.sh --port 8080` picks another port when 7746 is taken.
- **The address for links:** the installer asks for the address Spine puts in emails, PDFs and invitations, and suggests this machine's IP. Reserve that IP for the machine in your router so it doesn't change.
- **HTTPS with a domain:** `./install.sh --app-url https://spine.example.com` has Caddy get the certificate on ports 80 and 443.
- **HTTPS without a domain:** use Tailscale, which the field app also works with (`--behind-proxy`). The **HTTPS and domains** guide has the steps, and covers a Cloudflare Tunnel or your own proxy too.
- **One file fewer to download:** Spine's routing now comes in its own image, `spine-proxy`, so you no longer download `Caddyfile`. The files are install.sh, backup.sh, restore.sh, upgrade.sh, docker-compose.yml and env.example.
- **Clearer messages:** the installer says what to do when the port is taken, and it refuses `https://` on an IP or a `.local` name, which browsers can't trust, and says what to use instead.

The full list is in [CHANGELOG.md](https://github.com/haribrothers/spine/blob/main/CHANGELOG.md).
