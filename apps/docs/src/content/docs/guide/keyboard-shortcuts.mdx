Everything in Spine works from the keyboard. These shortcuts save time.

## Anywhere

| Keys | What it does |
|---|---|
| **Ctrl K** (**⌘ K** on a Mac) | Open search: find a contact, quote, invoice, job or page, or start an action |
| **↑** **↓**, then **Enter** | Pick a search result and open it |
| **Esc** | Close search, a menu, a dialog or a drawer; focus goes back where it was |
| **Tab** / **Shift Tab** | Move to the next or previous control; the focused one has a ring around it |
| **Enter** or **Space** | Press the focused button, tick a checkbox or open a menu |

## In quotes, invoices and bills

| Keys | What it does |
|---|---|
| **Enter** in the last line | Add a new line |
| **Alt ↑** / **Alt ↓** on a line | Move the line up or down |

## In lists and menus

| Keys | What it does |
|---|---|
| **↑** **↓** | Move through a menu's items or a list of options |
| **Enter** | Choose the highlighted item |
